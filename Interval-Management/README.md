# Interval Management

This folder contains algorithms developed to manage and merge overlapping time intervals efficiently.

### Solved Problems
* **MergeIntervals:** Merges overlapping intervals in an array to return a set of non-overlapping intervals.

### Technical Analysis
* **Approach:** In-place sorting ($O(N \log N)$) followed by a single-pass merge ($O(N)$).
* **Use Case:** Essential for financial systems, scheduling applications, and resource allocation tasks.
